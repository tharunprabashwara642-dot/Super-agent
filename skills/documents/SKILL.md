# Documents Skill
description: Create, edit, inspect, and deliver text documents and reports.
keywords: document, docx, report, letter, text file, word, document creation, report

## Rules
- Determine the requested format before generating the artifact.
- Preserve user-provided content unless asked to rewrite it.
- Use the project's native document tooling when available.
- Verify that the final artifact exists and is readable before reporting success.
