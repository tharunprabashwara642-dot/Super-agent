# Research Skill
description: Research a question using available web, search, files, and API tools.
keywords: research, search, web, investigate, sources, compare, latest, news, lookup

## Rules
- Separate facts from inference.
- Prefer current and authoritative sources when freshness matters.
- Cross-check important claims when multiple sources are available.
- Never invent a source, URL, quote, or result.
- Summarize findings clearly and retain useful source context.
